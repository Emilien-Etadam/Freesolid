# Polices de l'interface

IBM Plex Sans (400, 500, 600, 700) et IBM Plex Mono (400, 500), sous-ensembles
latin et latin étendu, au format WOFF2. Fichiers repris **tels quels** des
paquets npm `@fontsource/ibm-plex-sans` et `@fontsource/ibm-plex-mono`
(version 5.3.0), qui redistribuent les polices d'IBM.

Licence : SIL Open Font License 1.1 (`OFL-IBM-Plex-Sans.txt`,
`OFL-IBM-Plex-Mono.txt`). L'OFL permet de les embarquer et de les
redistribuer avec FreeSolid ; elles ne peuvent pas être vendues seules.

Déclarées dans `app/index.html` (`@font-face`, avec les plages Unicode
d'origine) ; voir `docs/ui-atelier.md`.
