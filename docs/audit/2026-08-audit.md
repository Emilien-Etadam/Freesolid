# P001 — Audit complet FreeSolid (août 2026)

## Résumé exécutif

Audit lecture seule de `engine/`, `app/` (hors `vendor/planegcs`), `tests/`,
licences et selftest. Le verrou global POST et le modèle « une action UI =
une transaction » tiennent. Les risques les plus graves sont **sécurité
localhost** (écriture fichier sans jail + CSRF via `Content-Type: text/plain`)
et **fuites d’état** (documents FreeCAD orphelins, IDs de sélection périmés
dans le PropertyManager, courses async refresh/preview/drag). Côté client,
`redraw()` d’esquisse et `rebuildPlanes()` allouent sans `dispose` — dette
GPU réelle, pas théorique. Le selftest couvre 75/86 ops ; 9 ops UI restent
sans exercice. Vérifs : `107` tests pytest OK, `node --check` OK sur les
quatre JS first-party.

**Décompte** : 2 bloquants · 14 majeurs · 22 mineurs · 12 suggestions
(≈ 50 constats).

## 1. Correction / bugs

### 1.1 — Course `refresh` / `refreshAny` sans jeton de génération

- **Sévérité** : majeur
- **Localisation** : `app/main.js:1592-1600`, `app/main.js:1264-1278`
- **Constat** : deux Ctrl+Z rapides (ou undo pendant un refresh) : la
  réponse la plus lente peut réappliquer un arbre/maillage plus ancien
  après un plus récent. `updateViewport` enchaîne deux `await` sans
  annulation.
- **Remède proposé** : compteur monotone ; ignorer tout résultat dont le
  seq n’est plus courant.
- **Effort** : S

### 1.2 — Aperçu jaune : requête en vol non annulée

- **Sévérité** : majeur
- **Localisation** : `app/main.js:340-351`
- **Constat** : le debounce 250 ms annule le timer, pas le `fetch` en
  cours ; un preview lent peut `showGhost` après un preview plus récent
  ou après fermeture du panneau.
- **Remède proposé** : id de génération + ignore si `!panel.active` ou
  seq obsolète.
- **Effort** : S

### 1.3 — Drag esquisse serveur : `sketch_move` concurrents

- **Sévérité** : majeur
- **Localisation** : `app/sketch.js:631-635`, `app/sketch.js:292-297`
- **Constat** : fallback serveur (solver local KO) : throttle 45 ms lance
  des `safe(sketch_move)` non ordonnés ; une réponse ancienne réécrit
  `mode.state` et peut « remonter » la géométrie.
- **Remède proposé** : une promesse in-flight + file du dernier `(x,y)`,
  ou seq sur les réponses.
- **Effort** : M

### 1.4 — `addRectangle` non awaité

- **Sévérité** : majeur
- **Localisation** : `app/sketch.js:348-351`
- **Constat** : après le 2ᵉ clic, `addRectangle` (4 `sketch_add_line`)
  n’est pas awaité ; l’utilisateur peut démarrer un autre outil pendant
  la construction → désynchro serveur/client.
- **Remède proposé** : `await addRectangle(...)` depuis un handler async,
  ou flag `busy`.
- **Effort** : S

### 1.5 — IDs face/arête invalidés dans le viewport, conservés dans le panneau

- **Sévérité** : majeur
- **Localisation** : `app/main.js:107-108`, `app/main.js:172`,
  `app/main.js:1814-1834`, `app/panel.js:48-50`
- **Constat** : `showMesh`/`showEdgeLines` vident correctement
  `selectedFaceId`/`selectedEdges`. Un Congé/Coque ouvert garde
  `values.sel` avec d’anciens IDs ; Ctrl+Z hors champ input
  (`main.js:603-606`) reconstruit la pièce → OK applique des IDs
  périmés (invariant architecture violé côté PropertyManager).
- **Remède proposé** : à chaque rebuild, vider les `selection` du panneau
  actif ou fermer le panneau.
- **Effort** : M

### 1.6 — Solveur local : `translate` → `null` saute la contrainte

- **Sévérité** : majeur
- **Localisation** : `app/solver.js:300-307`, `app/solver.js:127-128`
- **Constat** : seuls les `undefined` désactivent le solveur local ; un
  `null` (ex. Coincident sans points résolus) est ignoré → `load`
  réussit, le drag local sous-contraint diverge du serveur jusqu’au
  pointerup.
- **Remède proposé** : traiter `null` comme échec (`return false`) pour
  forcer le fallback serveur.
- **Effort** : S

### 1.7 — `move_component` avale l’échec du solveur

- **Constat** : `except KernelError: pass` après `_solve_assembly` → le

- **Effort** : S

## 2. Robustesse moteur

### 2.1 — `open_part` laisse un document orphelin

- **Sévérité** : majeur
- **Localisation** : `engine/kernel.py:1629-1644`
- **Constat** : après `_close_current()` + `App.openDocument`, absence de
  Body/Link → `KernelError` **sans** fermer ni adopter le doc → fuite
  dans `App.listDocuments()`.
- **Remède proposé** : `closeDocument` dans `except`/`finally` si le
  kernel n’adopte pas le doc.
- **Effort** : S

### 2.2 — `_import_cad` : échec `shape.read` laisse un doc vide

- **Sévérité** : majeur
- **Localisation** : `engine/kernel.py:1655-1662`
- **Constat** : `self._doc` pointe déjà vers un document neuf ; si
  `shape.read` échoue, `_body` reste `None` → état kernel incohérent.
- **Remède proposé** : sur échec, fermer le doc et reset `_doc`/`_body`.
- **Effort** : S

### 2.3 — `insert_component` : pièce sans Body laisse le doc ouvert

- **Sévérité** : majeur
- **Localisation** : `engine/kernel.py:183-192`
- **Constat** : `openDocument` puis raise si pas de Body ; le document
  pièce peut rester ouvert (s’il vient d’être ouvert).
- **Remède proposé** : fermer `part_doc` (s’il a été ouvert ici) avant
  raise.
- **Effort** : S

### 2.4 — Pas d’`UndoLimit`

- **Sévérité** : majeur
- **Localisation** : `engine/kernel.py:102-103`, `123-124`, `1631` ;
  confirmé vs `docs/optimisation.md` §6
- **Constat** : `UndoMode = 1` sans borne → pile d’undo + mémoire en
  longue session (chaque op esquisse est transactionnelle).
- **Remède proposé** : `doc.UndoLimit = N` (ex. 50–100) à la création /
  ouverture.
- **Effort** : S

### 2.5 — `dispatch` : `commitTransaction` silencieux

- **Sévérité** : mineur
- **Localisation** : `engine/kernel.py:3590-3594`
- **Constat** : échec de commit avalé → undo stack / doc potentiellement
  désalignés sans erreur client. Pattern abort sur Exception (L3583-3589)
  est correct pour le cas nominal.
- **Remède proposé** : propager ou logger si commit échoue.
- **Effort** : S

### 2.6 — `make_drawing` hors `_TRANSACTIONAL`

- **Sévérité** : majeur
- **Localisation** : `engine/kernel.py:702-756`,
  `engine/kernel.py:3540-3559`
- **Constat** : mute le doc (TechDraw) hors transaction ; cleanup manuel
  dans `finally` seulement. Si `removeObject` échoue (avalé), résidus
  possibles.
- **Remède proposé** : ajouter à `_TRANSACTIONAL` ou transaction locale
  dédiée + vérif post-cleanup.
- **Effort** : S

### 2.7 — Document actif multi-docs

- **Sévérité** : majeur
- **Localisation** : `engine/kernel.py:158-209`
- **Constat** : `insert_component` / `openDocument` changent
  `App.ActiveDocument` vers la pièce liée ; le kernel utilise surtout
  `self._doc`, mais des APIs FreeCAD implicites peuvent viser l’actif.
- **Remède proposé** : après ops multi-docs,
  `App.setActiveDocument(self._doc.Name)`.
- **Effort** : M

### 2.8 — Preview : abort échoué puis recompute

- **Sévérité** : mineur
- **Localisation** : `engine/kernel.py:1197-1206`
- **Constat** : `abortTransaction` avalé ; si abort échoue, recompute sur
  état partiel.
- **Remède proposé** : si abort échoue, forcer undo ou refuser l’aperçu.
- **Effort** : M

### 2.9 — Sweep / SubShapeBinder : cleanup incomplet hors KernelError

- **Sévérité** : mineur
- **Localisation** : `engine/kernel.py:1291-1323`
- **Constat** : binder nettoyé surtout sur échec `_recompute` ; exception
  hors ce chemin peut laisser un binder orphelin.
- **Remède proposé** : `try/finally` autour création binder→pipe.
- **Effort** : S

### 2.10 — Fichier assemblage temporaire fixe

- **Sévérité** : mineur
- **Localisation** : `engine/kernel.py:175-177`
- **Constat** : `saveAs(/tmp/freesolid-assemblage.FCStd)` — collision
  multi-process, jamais nettoyé.
- **Remède proposé** : nom unique (`NamedTemporaryFile`) + cleanup /
  saveAs utilisateur.
- **Effort** : S

### 2.11 — Verrou global

- **Sévérité** : suggestion (point sain)
- **Localisation** : `engine/server.py:33-36`, `62-64`
- **Constat** : `_KERNEL_LOCK` sérialise tout `dispatch` POST — correct

## 3. Sécurité

### 3.1 — Écriture / lecture fichier arbitraire via chemins client

- **Sévérité** : bloquant
- **Localisation** : `engine/kernel.py:1682-1692` (`save_part`),
  `994-1022` (`export_part`), `702-742` (`make_drawing`),
  `1616-1628` (`open_part`), `158-177` (`insert_component`)
- **Constat** : `expanduser(str(path))` puis I/O **sans sandbox**. Toute
  origine capable d’appeler `/api` lit/écrit où le process a les droits
  (`~/...`, `/etc/...` selon umask, écrasement de `.FCStd`/STL/STEP/DXF).
- **Remède proposé** : jail (`FREESOLID_DATA_DIR`), allowlist extensions,
  refuser `..` et chemins hors jail.
- **Effort** : M

### 3.2 — CSRF localhost sans Origin / token

- **Sévérité** : bloquant
- **Localisation** : `engine/server.py:51-64`, `87-93` ; bind
  `127.0.0.1` L102
- **Constat** : aucun check `Origin`/`Referer`, pas de CSRF token. Un
  site tiers peut POST *simple* (`Content-Type: text/plain` + corps JSON)
  vers `http://127.0.0.1:8787/api` sans preflight CORS ; le kernel
  exécute (`save_part`, `export_part`, …). Combiné à 3.1 = exfiltration /
  écriture.
- **Remède proposé** : exiger `Origin` ∈ allowlist locale + token de
  session au démarrage ; rejeter sinon.
- **Effort** : M

### 3.3 — Traversal statique `startswith` sans séparateur

- **Sévérité** : majeur
- **Localisation** : `engine/server.py:69-73`
- **Constat** : `normpath` + `startswith(_APP_DIR)` : bypass classique si
  un sibling préfixe existe (`…/app` vs `…/appX/...`). Symlink sous
  `app/` suivi par `open` (L76-77).
- **Remède proposé** : `os.path.commonpath([_APP_DIR, realpath(candidate)])
  == realpath(_APP_DIR)`.
- **Effort** : S

### 3.4 — `setExpression` sans allowlist

- **Sévérité** : majeur
- **Localisation** : `engine/kernel.py:1737-1745`, aussi
  `sketch_set_dim` (~2671)
- **Constat** : toute string non-float → `setExpression` ; moteur
  d’expressions FreeCAD (refs croisées) = surface d’injection
  paramétrique depuis le client.
- **Remède proposé** : parser/allowlist (idents, ops arithmétiques,
  `Variables.*`, dims nommées).
- **Effort** : M

### 3.5 — `set_param` / `set_params` hors whitelist `_EDITABLE_PROPS`

- **Sévérité** : majeur
- **Localisation** : `engine/kernel.py:1695-1716`, `1732-1736` ;
  contraste `get_params` L1530-1542
- **Constat** : `hasattr` suffit pour muter **n’importe quelle**
  propriété ; `get_params` est pourtant whitelisté.
- **Remède proposé** : appliquer `_EDITABLE_PROPS` aussi en écriture.
- **Effort** : S

### 3.6 — Validation protocol : présence seule, pas types/bornes

- **Sévérité** : majeur
- **Localisation** : `engine/protocol.py:128-151`
- **Constat** : `width: "x"`, `count: []` passent la validation ; erreur
  plus tard via `float(...)` → message « erreur moteur non traduite »
  (`kernel.py:3586-3589`).
- **Remède proposé** : schéma typé (str/float/int/list) + bornes.
- **Effort** : M

### 3.7 — `preview.params` opaque

- **Sévérité** : mineur
- **Localisation** : `engine/protocol.py:55` ; `kernel.py:1184-1199`
- **Constat** : nested `op`/`params` non re-validés par `OPS` avant
  `getattr`.
- **Remède proposé** : `validate_request` sur l’op imbriquée.
- **Effort** : S

### 3.8 — Pas de plafond Content-Length

- **Sévérité** : suggestion
- **Localisation** : `engine/server.py:56-57`
- **Constat** : DoS mémoire local possible.
- **Remède proposé** : cap 1–4 Mo.
- **Effort** : S

### 3.9 — Pas d’`eval`/`exec`/`pickle` dans `engine/`

- **Sévérité** : suggestion (point sain)
- **Localisation** : `engine/server.py:57`
- **Constat** : `json.loads` seulement. Risque restant = expressions +
  open FCStd, pas Python eval.
- **Remède proposé** : garder l’interdit ; durcir 3.1/3.4.
- **Effort** : —

## 4. Fuites et performance client

Recoupe de `docs/optimisation.md` : §1 re-tessellation **confirmée** ;
§3 JSON **confirmée** ; §4 preview 2× **confirmée** ; §5 redraw
**confirmée et aggravée** (pas de dispose) ; §2 drag local = fait (M3) ;
picking O(n) = non-problème à l’échelle actuelle **confirmé**.

### 4.1 — `redraw()` sans `geometry.dispose` / textures

- **Sévérité** : majeur
- **Localisation** : `app/sketch.js:180-264`, `151-166`
- **Constat** : chaque état recrée Line/Points/Sprite + `CanvasTexture` ;
  `Object3D.clear()` ne dispose pas → fuite GPU/CPU dès le drag.
- **Remède proposé** : avant clear, dispose géométries / `material.map` /
  materials non partagés.
- **Effort** : M

### 4.2 — `rebuildPlanes()` à chaque tessellation sans dispose

- **Sévérité** : majeur
- **Localisation** : `app/main.js:157`, `238-264`, `221-235`
- **Constat** : `showMesh` → `rebuildPlanes` → `planesGroup.clear()` +
  nouveaux `PlaneGeometry`/`EdgesGeometry`/sprites canvas.
- **Remède proposé** : dispose à la destruction ; ou rebuild seulement si
  `size` change.
- **Effort** : S

### 4.3 — Re-tessellation intégrale après chaque op

- **Sévérité** : majeur (perf grosses pièces)
- **Localisation** : `app/main.js:193-196`, `1592-1597`
- **Constat** : chaque op → `tessellate` + `tessellate_edges` complets
  (corps actif + autres + surfaces). Invisible sur pièces de test.
- **Remède proposé** : cache serveur par `Shape.hashCode()` / empreinte.
- **Effort** : L

### 4.4 — Fantôme plan de référence sans dispose

- **Sévérité** : mineur
- **Localisation** : `app/main.js:647-670`
- **Constat** : `refreshDatumGhost` remove sans dispose.
- **Remède proposé** : traverse + dispose avant remove.
- **Effort** : S

### 4.5 — Outlines assemblage : matériaux non disposés

- **Sévérité** : mineur
- **Localisation** : `app/main.js:1206-1230`
- **Constat** : géométries disposées ; chaque `LineBasicMaterial`
  d’outline réalloué jamais disposé.
- **Remède proposé** : matériau partagé ou dispose.
- **Effort** : S

### 4.6 — Poids JSON maillage (doubles pleine précision)
